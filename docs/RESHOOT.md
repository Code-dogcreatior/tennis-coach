# 数据缺口与补拍清单

## 当前缺口（2026-11-17）

| 缺口 | 现状 | 影响 |
|---|---|---|
| 侧面机位、单人、固定机位的**真实时间**挥拍 | 公开数据里没有找到；THETIS 是正面机位；YouTube 侧面素材大多是倍率未知的慢动作或剪辑合集；Wawrinka 侧面单反等 5 个视频因 YouTube 限流（429）没能下载 | 首版优先支持的侧面机位，**没有带真值的评测**；侧面正反手规则（肩部前后顺序）没有经过调参验证 |

| 左手持拍样本 | 只有 Nadal 正面练习片段，以及 THETIS 中画面呈现为右手的 3 名球员 | 镜像只有单元测试和少量真实样本验证 |
| 教练审核过的参考 | 没有 | 参考库全部是“参考示范”，不能作为专业标准 |
| 阶段事件真值 | 没有逐帧标注 | 阶段误差只做了人工抽查，见 REPORT.md |

## 补拍清单（每项建议 ≥5 名球员 × 每人 ≥5 次）

拍摄要求：手机横屏，**60 fps 或更高（不要使用慢动作模式，或注明慢放倍率）**，三脚架固定，**全身入镜且头顶、脚底留出余量**，球员在画面中高度 ≥ 1/3，画面里只有一名球员，光线充足，每段视频包含“准备 → 引拍 → 击球 → 随挥 → 收拍”的完整一次挥拍（多次也可以，系统会自动切分）。

| # | 动作 | 机位 | 持拍手 | 说明 |
|---|---|---|---|---|
| 1 | 正手 | 侧面（摄像机在持拍手一侧，距离 4–6 m，高度约 1.2 m） | 右 | 首版核心 |
| 2 | 正手 | 侧面（非持拍手一侧） | 右 | |
| 3 | 单手反手 | 侧面（持拍手一侧） | 右 | |
| 4 | 双手反手 | 侧面（持拍手一侧） | 右 | |
| 5 | 发球 | 侧面（面向发球方向的左侧/右侧各一组） | 右 | 抛球手、持拍手都要完整入镜 |
| 6 | 1–5 全部 | 同上 | **左** | 用来验证镜像 |
| 7 | 正手/反手 | 正面（隔网正对） | 右/左 | 与 THETIS 互补，并且是实时有球 |
| 8 | 非目标动作 | 侧面 | 任意 | 截击、高压、挑高球、空挥拍、走动、捡球，用来评测拒识 |
| 9 | 质量对照组 | 侧面 | 任意 | 故意拍摄：脚被裁掉、多人入镜、逆光、远距离（球员 <15% 画面高度）、30 fps，用来验证质量检查 |
| 10 | 教练示范 | 侧面 | 任意 | 由教练确认“合格”，标注风格（如“紧凑引拍/大引拍”），作为教练审核参考 |

每段视频请记录：球员（化名即可）、持拍手、水平、机位（距离/高度/角度）、帧率、是否慢动作、授权说明（本人同意用于训练分析；是否允许商用/再分发）。

## 标注需求（用于严格评测）

* 每次挥拍的动作类别（4 类 + 非目标）
* 关键帧：引拍开始、引拍终点、击球（有球时以球拍触球帧为准）、随挥结束；发球另加抛球最高点、拍头最低点
* 持拍手、机位
